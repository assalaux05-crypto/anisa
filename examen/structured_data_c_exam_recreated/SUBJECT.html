Part A — Fundamentals: CSV 3 exercises

Each exercise has its own directory, CSV fixture, exact prototype, starter source, test main and Makefile.

Exercise 1 — decimal to unsigned

unsigned parse_unit(char *decimal);

Convert a decimal string from the CSV using atoi, then return an unsigned value. Fixture: units.csv.

Exercise 2 — read one field

char *parse_field(char **input);

Return a pointer to the field before the next comma, replace the comma with NUL, and advance the input cursor. Preserve empty fields. Fixture: fields.csv.

Exercise 3 — authors and books

struct author *parse_author_row(char *row);
void print_all_books_written_by(char *author_lastname);

Parse id,lastname into an author struct. Use authors.csv to find the ID, then books.csv to print every matching book title.

Assumption for exercises 2–3: a simple CSV subset without quoted commas. The field function allocates its result; the caller must free it. The author parser allocates both the struct and its name.

YAJL identification

YAJL headers:  <yajl/yajl_tree.h>  <yajl/yajl_parse.h>  <yajl/yajl_gen.h>
Linker flag:   -lyajl
Debian/Kali:   sudo apt install libyajl-dev

“JAJL” is likely YAJL, but check the actual header. If it is <jansson.h>, the library is Jansson and uses different functions.

Moulinette rules

  • Do not change prototypes.
  • Check NULL, missing files, malformed input and allocation failures.
  • Preserve empty CSV columns; do not lose the last field after a trailing comma.
  • Free every allocated CSV field, struct, file buffer and YAJL object/handle.
  • Check YAJL node types before accessing their values.
  • Remember YAJL callback strings are length-delimited, not necessarily NUL-terminated.
  • Compile with -std=c99 -pedantic -Wall -Wextra -Werror -Wvla.
