Structured Data Parsing

Mock TP · C Programming · Manual CSV + Library-based JSON · 40 exercises

Exam direction: Part I is CSV parsed manually without a CSV library. Part II is JSON parsed with the library supplied by the teacher. The precise JSON library is not specified in this pack, so its statements are API-neutral. See docs/JSON_LIBRARY_QUICK_REFERENCE.md for common API mappings.

Introduction

This practice TP is organized like an exam repository: independent exercise directories, strict prototypes, points, fixtures, starter source/header files, and a small test main. Exercises progress from basic file reading to robust parsers, nested structures, validation, mutation, serialization, and recovery cases.

General rules: compile with C99 and warnings enabled; check every file operation and allocation; do not change prototypes; free all resources; do not assume records are well-formed unless the exercise says so.

EXERCISE 01 · Level 1 — Easy · 1.0 POINTS

Count data records

Count data records, excluding the header. Ignore completely empty lines. The file may end with or without a final newline.

Required prototype

size_t csv_count_records(const char *path);

Suggested steps

  1. Open the file with fopen(path, "r").
  2. Read the first line as the header; if there is no line, return 0.
  3. Read the remaining lines with fgets and count only lines that contain a non-whitespace character.
  4. Always close the file, including error paths.

Useful functions / APIs: fopen, fgets, fclose, isspace

Test these cases: Missing file; empty file; header only; blank lines; final line without \n.

Expected fixture result: 3 data records.

Code folder: csv_01_count_records

EXERCISE 02 · Level 1 — Easy · 1.0 POINTS

Count columns in the header

Return the number of comma-separated columns in the first line. For this first exercise, assume the header contains no quoted commas.

Required prototype

size_t csv_count_fields(const char *path);

Suggested steps

  1. Open the file and read only the first line.
  2. An empty header has zero fields; otherwise the number of fields is commas + 1.
  3. Do not count commas after the line terminator.
  4. Close the file and return 0 on open/read failure.

Useful functions / APIs: fopen, fgets, strchr or a for loop, fclose

Test these cases: One-column header; empty file; trailing comma (it means an empty last field).

Expected fixture result: 4 header fields.

Code folder: csv_02_count_fields

EXERCISE 03 · Level 1 — Easy · 1.5 POINTS

Extract a field from a simple CSV line

Copy the field at zero-based index into out and terminate it with \0. Return 1 on success and 0 for invalid arguments, missing field or insufficient output capacity. This level assumes no quotes.

Required prototype

int csv_get_field(const char *line, size_t index, char *out, size_t out_size);

Suggested steps

  1. Validate line, out and out_size.
  2. Walk through characters and count commas until the requested field starts.
  3. Copy until the next comma or line ending; do not overflow out.
  4. Write the null terminator and return success.

Useful functions / APIs: strlen, strchr, memcpy or a character loop

Test these cases: Index 0; last field; empty field; index out of range; buffer too small.

Expected fixture result: Index 1 gives Manel.

Code folder: csv_03_get_field

EXERCISE 04 · Level 1 — Easy · 1.5 POINTS

Convert a field into an integer safely

Parse one complete base-10 integer. Accept surrounding whitespace; reject empty strings, trailing junk and overflow. Do not use atoi.

Required prototype

int csv_parse_long(const char *text, long *value);

Suggested steps

  1. Skip leading whitespace with isspace.
  2. Call strtol(text, &end, 10) after setting errno = 0.
  3. Reject when no digits were consumed, errno is ERANGE, or non-whitespace remains.
  4. Store the result only after all checks pass.

Useful functions / APIs: strtol, errno, ERANGE, isspace, limits.h

Test these cases: 0; negative values; + sign; spaces; "12x"; empty string; overflow.

Expected fixture result: " -42 " succeeds with -42; "12x" fails.

Code folder: csv_04_parse_long

EXERCISE 14 · Level 3 — Difficult · 3.0 POINTS

Parse a quoted CSV record

Implement a one-line CSV parser that supports quoted fields, commas inside quotes and escaped quotes represented by doubled quote characters. Reject malformed quoting and capacity overflow.

Required prototype

int csv_parse_quoted_line(const char *line, CsvField *fields, size_t capacity, size_t *field_count);

Suggested steps

  1. Use states: FIELD_START, UNQUOTED, QUOTED and AFTER_QUOTE.
  2. A comma ends a field only outside quotes.
  3. Inside a quoted field, two consecutive quotes produce one literal quote.
  4. After a closing quote, accept only comma, line ending or end-of-string.
  5. Always terminate each field and report field_count.

Useful functions / APIs: manual state machine, strlen, size_t bounds

Test these cases: Empty field; empty quoted field; quote in unquoted field; characters after closing quote; unclosed quote; field too long.

Expected fixture result: Three fields; second is Doe, Jane; third is He said "hello".

Code folder: csv_14_parse_quoted_line
