# TOML — manual parsing (1.5 pts)

Implement:
- `toml_get` for a string value inside a named table (0.75 pt).
- `toml_update_int` for an integer value inside a named table (0.75 pt).

Support simple `[table]` headers, `key = value`, optional surrounding spaces, and quoted basic strings. Arrays, dates, inline tables and multiline strings are out of scope.
