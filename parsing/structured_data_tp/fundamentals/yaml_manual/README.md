# YAML — manual parsing (2 pts)

Implement:
- `yaml_get` for a top-level scalar (0.75 pt).
- `yaml_set` to replace or append a scalar (0.75 pt).
- `yaml_count_modules` for the simple `- value` list under `modules` (0.5 pt).

Only the shown subset is required: no nested mappings, quoted escape processing, anchors, aliases, tags or multiline scalars. YAML is much richer than this subset; do not claim this is a complete YAML parser.
