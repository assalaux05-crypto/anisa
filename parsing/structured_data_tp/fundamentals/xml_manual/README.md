# XML — manual parsing (1.5 pts)

Implement:
- `xml_get_text` (0.5 pt).
- `xml_count_students` (0.5 pt).
- `xml_set_text` (0.5 pt).

Only simple, non-nested target elements with plain text are required. This is a deliberately tiny exercise, not a conforming XML parser: real XML requires handling attributes, entities, namespaces, comments, CDATA, encoding and nesting.
